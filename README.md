# KeenKeeper 

KeenKeeper is a  relationship management app that helps you stay connected with the people who matter most. Track when was the last time and when is the next time to connect.



##  Technologies Used

- **Next.js** — React framework for building the app
- **Tailwind CSS** — Utility-first CSS for styling
- **Recharts** — Chart library for the analytics page
- **React Icons** — Icon library
- **localStorage** — Browser storage for saving timeline entries



##  Key Features

### 1.  Friend Tracking
View all your friends in a clean card layout. Each card shows the friend's photo, name, tags, days since last contact, and their current status — overdue, almost due, or on track.

### 2.  Timeline
At a glance , see with whose you have connected so far.

### 3.  Friendship Analytics
The Stats page shows a Pie Chart of all your interactions broken down by type, in a very interactive way.
